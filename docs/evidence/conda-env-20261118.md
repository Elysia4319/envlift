## 只读扫描与重叠修复

修复后 `conda.NewScanner().Scan` 实际输出：

```text
found=true envs=3 warnings=0
AIC base=false py=3.14.8 conda=20 pip=7 manager=D:\Conda\miniconda3
base base=true py=3.14.8 conda=146 pip=7 manager=D:\Conda\miniconda3
pytorch base=false py=3.12.14 conda=273 pip=52 manager=D:\Conda\miniconda3
```

对比修复前：base pip 97 → 7，pytorch pip 186 → 52。`conda list` 中 `channel=pypi` 的条目进入 pip 清单，随后按 PEP 503 规范化名称剔除与 conda 非 pypi 包的重叠；`requirements.txt` 不再重复包含 numpy 等 conda 包。

所有扫描环境默认 `restore_conda=false`、`restore_pip=false`；base 只读。`--conda-packages` 默认 `none`，必须显式选择 `conda|pip|both`。

## VM 实测结果

| 场景 | 结果 | 关键输出 |
|---|---|---|
| scan | 通过 | 发现 `base` + `C:\My Apps\conda测试`；base 只读；命名环境默认两个开关 false；中文/空格 prefix 未丢字符 |
| create | 通过 | `conda create --yes --prefix "C:\My Apps\conda-create测试" --override-channels -c conda-forge --file environment.yml`；随后 pip 安装 requests；报告 succeeded |
| create 第二次 apply | 通过 | 计划 skipped，未执行安装命令 |
| update | 通过 | 缺 pandas 时执行 `conda install --yes --prefix ... --override-channels -c conda-forge --file specs.txt`；不再使用 `conda env update --yes`；报告 succeeded |
| update 第二次 apply | 通过 | 计划 skipped |
| pip | 通过 | `<prefix>\python.exe -m pip install -r requirements.txt`；rich 安装并校验通过 |
| 镜像临时文件 | 通过 | 失败场景保留 `condarc`（`channels: [conda-forge]`）与 `pip.ini`（`index-url = https://pypi.org/simple`）；成功场景临时目录清理 |
| 失败注入 | 通过 | 无效包导致 install 失败；环境仍可 `import numpy, pandas`；报告 failed，不显示 succeeded |
| 缺包 unverified | 通过 | 包装器让 `conda list` 返回空、其余委托真实 conda；真实装好 tabulate 后报告仍为 `unverified`（1），exit 2 |
| base 只读 | 通过 | dry-run 中 base 为 `manual`，不会自动修改 |
| `--conda-packages=none` | 通过 | 命名环境 skipped，不影响软件/PATH 阶段 |
| 成功清理 | 通过 | `create_exists=False`、`update_exists=False` |

说明：缺包 unverified 使用 VM 内包装器注入（`conda list` 返回空，install 仍委托真实 conda）；其余 create/install/pip 均为真实 conda 操作。

原始命令输出、journal 与报告 JSON 见 `docs/evidence/conda-env-20261118/README.md` 及同目录文件。

CLI 显式覆盖补验：fresh-scan 风格配置（两个 per-env 开关均为 false）不传 flag 时 skipped；`--conda-packages=conda` 时生成 `conda install` 计划。原始输出见 `explicit-none.txt` / `explicit-conda.txt`。
